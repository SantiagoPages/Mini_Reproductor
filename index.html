Configurar Spotify

Se hace una sola vez (unos 3 minutos). Necesitás Spotify Premium.

  1. Abrí el panel y creá una app (el nombre es libre). Marcá Web API y Web Playback SDK.
  2. En Redirect URI poné http://127.0.0.1:8888/ y guardá.
  3. Copiá el Client ID de tu app y pegalo acá:
